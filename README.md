## Running the experiments / 运行实验

Use Python 3.13. Run these commands from the project folder:

使用 Python 3.13，在项目文件夹内执行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
bash run_all.sh
```

The script trains the models and runs the analyses using the included data. Results are saved in `results/`, and figures in `report/figures/`. It runs on CPU and does not require API keys. Full training may take considerable time; numerical results can vary across environments.

脚本使用随附数据训练模型并运行分析。结果保存在 `results/`，图表保存在 `report/figures/`。使用 CPU 运行，不需要 API 密钥。完整训练需要一定时间，不同环境下的数值可能略有差异。

The PDF is the finished report and is not regenerated by this script.

PDF 是已完成的报告，运行脚本不会重新生成其排版。
